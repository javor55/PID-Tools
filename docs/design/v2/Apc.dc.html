Průvodce · Dopředná vazba

Kdy použít: měřená porucha s výrazným vlivem na PV. Regulátor se ladí normálně, FF až potom.

Co je potřeba: model MV → PV a model DV → PV (oba z Modelu ✓).

Zavádění: začněte se zesílením 50–80 % a ověřte na provozu.
