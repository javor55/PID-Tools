# Návrh UI v2 – kopie desek z artefaktu

Zdroj: https://claude.ai/artifact/QuLnUL4JG1Y6jKfAGcmhD9 (verze 37, 11. 11. 2026). Artefakt je hlavní verze; tady je kopie pro práci bez přístupu k němu. Soubory `.dc.html` jsou desky návrhu (statické HTML + `renderVals` s ukázkovými daty); bez `support.js` z artefaktu se `{{…}}` a `sc-for` nevykreslí, obsah a rozvržení jsou ale čitelné.

| `DataTrends.dc.html` | Data › Trendy – prohlížeč všech signálů, kurzory |
| `Data.dc.html` | Data › Kvalita dat – záznam, signály, kontroly |
